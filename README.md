# تموينات دانة البركة — الإصدار المطور 0.2

نسخة ويب محلية للجوال والكمبيوتر.

## التشغيل
1. Python 3.11+
2. `pip install -r requirements.txt`
3. `python app.py`
4. افتح `http://127.0.0.1:5000`

الدخول الأولي: `admin` / `admin123` (للتجربة فقط، غيّرها قبل الاستخدام الحقيقي).

## الجديد
- تسجيل دخول ومشرف/موظف وصلاحيات بيع/مخزون/مشتريات.
- سجل تدقيق للعمليات.
- مصروفات يومية.
- البيع الآجل وربطه برصيد العميل.
- مرتجع كامل بقيد عكسي دون حذف أو تعديل الفاتورة الأصلية.
- زر إرسال ملخص الفاتورة إلى واتساب للعميل المسجل.
- استمرار ربط باركود الحبة/الحزمة/الكرتون، تنبيهات التكلفة والصلاحية والركود والمخزون.

## مهم قبل التشغيل التجاري
زر واتساب الحالي يفتح محادثة جاهزة للمستخدم؛ الإرسال التلقائي الحقيقي يحتاج WhatsApp Business API واعتماد بيانات المنشأة. كذلك يلزم تهيئة ضريبة القيمة المضافة والفوترة الإلكترونية حسب حالة المنشأة ومتطلباتها، نسخ احتياطي، HTTPS، وسياسة كلمات مرور أقوى.
